## 4. Batch 5 — Devin Jatho Keyword-Punch Style (branch `rocky/skills-templates`)

- **Style (from reference reel Da2x2TaSmUH, @devinjatho — the same creator as the raw video):** NO conventional captions. The caption system IS huge keyword/phrase pop-ins: extra-bold condensed ALL-CAPS, centred mid-frame (chest height), 1–3 words on 1–2 lines, ~60–80% frame width, soft dark glow, NO pill/box/outline. Pop in hard ON the spoken keyword, vanish after ~1–2s. Colour code: white = neutral, bright red = "bad"/old, bright green = "good"/new power words, bright blue = the key term. Graphics ONLY where needed (user's order): no forced card sequences, no lower-thirds, no progress bars, ONE text on screen at a time. Sound: voice ONLY — no music bed, no SFX. Pacing: one continuous take, keyword changes every ~2s + punch-in zooms.
- **Key design decision:** keyword pops render ONLY via the graphics engine as a new element type `keyword_pop` (V2 clips); the `keyword_punch` caption preset produces ZERO caption events (header-only ASS). One rendering path only — no double-render risk, no double text.
- **What was built:** `backend/caption_presets.py` — new preset `keyword_punch` (13th; early-returns zero events, real word count). `backend/graphics.py` — `keyword_pop` classifier entry (before the emphasis entry), `GfxKeyword` style (Impact 130, ScaleX 88 / ScaleY 112, Shadow 4, Alignment 5), role colours, pop position (540, 1130), measured-width fitting via `_fit_text` with `em_scale` 0.72 (Impact-condensed), hard pop-in `\fs148→\fs130` settle in 120ms, `\blur4`, no fade. `backend/motion_planner.py` — `plan_motion_graphics(..., keyword_punch=True)`: no hook title card (first pop IS the hook), one pop per ~1.5–2s speech beat around the highest-scoring word (digit/money +4, number/emphasis/negative/good +3, topic +2, content +1, stop −2), colour priority red > green > blue > white, contiguous-window phrase selection (never skips words — the first build's skip-stop-words expansion made Frankenstein phrases like "leaders media only"), edge punctuation stripped, hold ≥0.7s cap 2.5s, cap 40 pops, card sequence (same genuine 3+ ascending-marker rule) reserves its span, pops win over emphasis/proof in gaps, zooms = first pop + 3 strongest, max 4, 12%. `backend/ollama_planner.py` — `keyword_pop` element type with colour field, punch-mode prompt (pop rules + colour definitions + restraint, `num_predict` 2048 so long pop plans don't truncate mid-JSON), validator: 40-pop cap, >3-word trim, >2.5s clamp, pop–pop overlap shift/drop, pops-win phase trims/drops drawn segments overlapping pop windows (zooms exempt), hook requirement waived (≥1 pop required instead), title_card/lower_third/progress_bar/emphasis dropped in punch mode. **Restraint (global):** "NEVER emit card_sequence unless the speaker literally lists steps"; pills/proof only for genuine number/money/emphasis moments. **Grounding validation (global):** pill/proof/card-label/keyword text must be a contiguous word-sequence match against the transcript (case-insensitive, punctuation ignored, magnitude expansion `1.2m`→`1.2 million`, numeric-core equality `$5`==`5`); ungrounded segments dropped with repair notes, never rejecting the whole plan (title_card/lower_third/emphasis exempt — hook titles are summaries). `backend/templates.py` — new template `devin_keyword_punch` (keyword_punch preset, `creator_motion_graphics_style`, no SFX, no music, `hook_block: False`, one continuous take). `backend/pipeline_v3.py` — punch mode forces SFX `[]` (overrides job placements AND defaults, survives persisted-EDL leftovers) and skips the music bed; Frontend: `devin_keyword_punch` template card in `app.js`, `keyword_punch` in the cap-chip + custom-style select in `index.html`.
